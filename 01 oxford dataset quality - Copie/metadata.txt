- Pseudo-OCV charge/discharge cycles

Dynamic load profile:
Present

Dynamic profile:
Urban Artemis-derived variable-current discharge profile

Real-world operation:
Absent; the profile is laboratory replay of a
representative driving cycle rather than measurements
collected from vehicles in operation.

5. REPRESENTATIVENESS AND DIVERSITY
============================================================

Chemistry diversity:
1 chemistry

Temperature diversity:
1 temperature condition (40°C)

DoD diversity:
Limited; the cells are primarily subjected to the
same drive-cycle-based cycling protocol

C-rate diversity:
Limited; the main ageing protocol uses a variable-current
drive-cycle profile, while characterization includes
1-C and low-current pseudo-OCV tests. These characterization
currents are not treated as independent ageing conditions.

Replicate cells/vehicles:
8 independent cells

Calendar aging:
Absent as a dedicated experimental condition

Dynamic load profiles:
Present; Urban Artemis-derived variable-current profile

Real-world operation:
Absent; laboratory cycling using a prescribed drive-cycle
profile


============================================================
6. CHARACTERIZATION AND DEGRADATION INFORMATION
============================================================

Capacity characterization:
Performed every 100 drive cycles

SOH-related information:
Capacity measurements are available from characterization
tests and can be used to derive capacity-based SOH.

Degradation trajectory:
Long-term ageing measurements are available across the
testing period.

End-of-life definition:
No explicit universal end-of-life threshold is specified
in the dataset description; degradation progression is
observed through the recorded measurements.


============================================================
7. METADATA-BASED QUALITY EVIDENCE
============================================================

Correctness:
Physical plausibility and signal consistency require
direct analysis of the recorded measurements.

Completeness:
Missing values and temporal continuity require direct
analysis of the MATLAB data.

Test protocol documentation:
Available through the official dataset documentation.

Anomaly and noise control:
Requires signal-level analysis.

Distribution balance:
SOH range and SOH distribution require calculation from
capacity measurements.

Cycle contribution per cell:
Eight cells are available; the number of valid cycles
per cell must be determined from the recorded data.

Temporal coherence:
Requires direct analysis of timestamps, cycle identifiers,
and degradation trajectories.

============================================================
5. AVAILABLE DATA
============================================================

Recorded variables (columns in each vehicle#N.xlsx):

* time                -- timestamp of each sample
* vhc_speed           -- vehicle speed
* charging_signal     -- mode indicator (1 = charging, 3 = driving)
* vhc_totalMile       -- cumulative mileage
* hv_voltage          -- pack voltage
* hv_current          -- pack current
* bcell_soc           -- state of charge
* bcell_maxVoltage    -- maximum cell voltage
* bcell_minVoltage    -- minimum cell voltage
* bcell_maxTemp       -- maximum cell temperature
* bcell_minTemp       -- minimum cell temperature

Current convention (verified from raw CAN data):
NEGATIVE = charging
POSITIVE = discharging / traction
Note: some secondary sources state the opposite; the raw CAN
signal is authoritative. Driving includes regen braking, so a
legitimate fraction of driving rows is negative.

Sampling:
0.1 Hz or 0.5 Hz depending on the vehicle.

Data volume:
~12.83 million observations (paper).
Public GitHub release: 1 month per vehicle.

============================================================
7. PHYSICAL BOUNDS (paper-derived + exploration-refined)
============================================================

The following bounds are derived from the reference paper and
refined during data exploration. They are used by the
physical-plausibility check in the quality-assessment code.

Pack-level:

* Pack voltage (per chemistry, exploration-refined):
    NCM: 250 -- 400 V
    LFP: 450 -- 620 V
    (Paper Fig. 2(d) shows the overall pack-voltage range;
    the code splits by chemistry for tighter QC.)

* Pack current:
    -350 -- +200 A
    (Paper Fig. 2(e) shows the dynamic current profile;
    bound widened during exploration to cover regen and
    fast-charge transients.)

* Battery temperature (max cell temperature):
    0 -- 60 C
    (Paper Fig. 2(h,i) reports 10 -- 40 C; the bound was
    widened to cover summer operation and individual sensor
    glitches at 255 C are still flagged.)

* Ambient temperature:
    0 -- 30 C (paper Fig. 2(c))

Cell-level:

* Cell voltage:
    2.5 -- 4.2 V (NCM) / 2.0 -- 3.65 V (LFP)
    Paper Fig. 2(f,g) shows cell voltages. Some readings >6 V
    were flagged as errors in the paper.

* Cell temperature:
    10 -- 40 C (paper Fig. 2(h,i))


============================================================
8. BATTERY STATE AND DEGRADATION
============================================================

SOC:
Directly available from the BMS.

Initial capacity:
Available for each vehicle (120 -- 645 Ah).

Direct SOH:
Not directly provided.

SOH derivation:
Ah-integration during charging segments with ΔSOC > 20%.
Formula: SOH = C_now / C_rated × 100%.
Post-processing: Z-score outlier removal + LOWESS smoothing.

Discharge capacity:
Not directly provided as a dedicated cycle-level measurement.

Long-term degradation:
Limited by the observation period (1 month public / 1 year full).

End-of-life:
Not specified.


============================================================
9. DATA CLEANING (paper)
============================================================

1. Remove duplicates based on timestamp
2. Match environmental temperature (Weather API + GPS)
3. Detect outliers (IQR method) -> replace with adjacent values
4. Segment data (Driving / Charging / Resting)
5. Filter charging segments (ΔSOC > 20%)
6. Fill missing values (linear interpolation)


============================================================
10. LIMITATIONS (paper)
============================================================

- Pack-level only (no per-cell data)
- Temperature range limited (0 -- 30 C ambient)
- Same-platform bias (Guangzhou only)
- No extreme conditions tested
- Some pack structures confidential
